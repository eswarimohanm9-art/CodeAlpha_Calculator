# Calculator

A simple calculator built using HTML, CSS, and JavaScript.

## Features
- Addition, Subtraction, Multiplication, and Division
- Clear (C) button
- User-friendly interface
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project files.
2. Open `index.html` in a web browser.
